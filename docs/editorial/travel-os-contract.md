# Travel OS v1：数据与设计契约

版本：2026-09-27。对应 M0，首个实现范围为北京故宫 → 景山一日样板。后续三城范围仍是北京、上海、西安；本轮不把旧 42 城自动升级成执行级资料。

## 数据字典与共享规则

实现：`src/lib/content/schema.ts`；内容：`beijing-day.ts`。

| 实体 | 关键字段与约束 |
| --- | --- |
| Fact<T> | value 可空；state 为 verified/pending/conflicting/expired；sourceIds、checkedAt、reviewAfter。未知值保持 null；reviewAfter 到期由 factUsable / preflight 判断，不篡改原始核验记录 |
| Evidence | 稳定 id、URL、标题、official/provider/editorial、核验日期、冲突说明 |
| Place | 稳定 id、cityId、双语名称、地址事实、入口 ID、图像引用、预约与通行事实、编辑建议时长 |
| Entrance | 独立于景点主体；入口/出口角色、中文导航词、带坐标系的位置、车辆下车点、步行到达说明 |
| TravelCard | 引用 entranceId；中英文标题、中文展示句及用途、注意事项。地址从所引用地点读取，不另存副本 |
| DayPlan / RouteStop | 固定版本与 ID、时间窗口、活动/交通/休息角色、地点及入口引用。时间窗口不等于已出票班次或预约 |
| JourneyOptions | 日期可未知、1–8 人、用户自报 checklist、选中的 cardIds。日期、整数、ID 白名单均做服务端验证 |
| BudgetLine | CNY 每人估算区间；人数乘算；始终标为编辑预算，并非现价 |
| AmapPoi / AmapWalk | 提供方、抓取时刻、GCJ-02、地址/营业信息/步行距离与耗时；与 verified 编辑事实分离 |

同一地点被网页、PNG 卡、PDF 通过稳定 ID 引用。不存在的地址、下车点、坐标或交通时刻不得猜测补齐。用户勾选只说明“用户已确认”，不改变官方事实状态，不触发任何预订。

旧数据经 `legacy-adapter.ts` 输出 introductory / executionReady=false；已有 42 城 URL、照片许可、收藏与规划功能保留。三城更完整的 City、TransportHub、Transfer、Trip、BookDocument 在下一阶段按本契约扩展，当前未声称已落地完整模型。

## 视觉系统

- 背景 #f8f7f2；深绿 #203d33；信息灰 #646d61；提醒陶红 #a4523b；线条 #d6d9cc。
- 标题 Georgia；正文沿用网站字体；中文卡 Noto Sans SC（本地字体，SIL OFL）。网页与 PDF 独立排版，共享内容。
- 摄影：只用许可档案中的实景图。当前照片为景山视角看故宫，不能描述为午门近景。附作者、许可、原图链接。
- 方向示意图：南入北出、入口/出口和公园关系；明确“非比例、过街位置示意”，不得当作导航。
- 参观动线：编号日程、时间窗口、建议时长、行动信息；空缺的酒店转移时间保持未知。
- 信息卡：中文目的地最大，展示句其次；用途、导航词、地址和不确定事项分层；支持复制、PNG、选择后进入 PDF。
- 高德实时路线：在线提供方数据；单独标注坐标系与抓取时间；没有街道底图，不冒充精确离线地图。
- 响应式：桌面主内容/侧栏；窄屏单列；卡片在小屏纵排；主要按钮最小可触达高度由版式保障。

## 交互与输出契约

借鉴用户 HTML 的日程、预算、准备清单、实用工具工作区；不复制其浏览器 Key 存储和用直线距离推算出行时间的方式。

- 日期、人数、清单、卡片集合保存到按内容版本隔离的 localStorage；损坏存档回退默认；存储失败有提示。
- 卡片可加入/移除本日旅行册，也可仅查看已选卡。此处“加入”不是全站多日行程编辑器。
- PNG 和 PDF 可在断网时读取；网站本身没有 Service Worker，不承诺离线网站。
- PDF 使用完整嵌入的中文字体，避免已复现的 CFF 子集渲染空白。默认样板 12 页，约 14.2 MB。
- 六类核心版式已实现：封面、日程、方向/交通、景点执行、中文卡、Plan B；另有准备/预算、来源页。
- PDF 服务端限制请求 16KB、单进程最多同时生成 2 份。生产部署仍需跨实例限流、生成队列和订单交付。

## 验收门槛与已知范围

代码验证包括实体引用、日期合法性、周一/过期检查、缺失 Key、配额和网络错误、错误入口、路线空数据。实际页面与 PDF 需另做视觉检查，不能以编译通过替代。
