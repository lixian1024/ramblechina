我会把产品定位从“旅游攻略网站”进一步收紧成：

> **China Unfold = 面向第一次/前几次来中国的外国游客，一套视觉化、可执行、可离线使用的 China Travel Operating System。**

核心不是“信息比别人多”，而是把外国游客在中国旅行时最麻烦的事情提前处理掉。

### 1. 免费网站：负责获客，不要把完整 PDF 简单搬上网页

免费层应该覆盖大量城市，适合 Google 搜索和用户浏览，例如：

**Beijing Travel Guide → Shanghai → Xi'an → Chengdu → Guilin → Zhangjiajie……**

每个城市至少应该形成这种结构：

| 模块内容            |                  |
| --------------- | ---------------- |
| Why go          | 为什么值得去           |
| Best time       | 最佳季节 + 每月体验      |
| How many days   | 1/2/3/4 天分别怎么玩   |
| Where to stay   | 推荐住宿区域，而不是简单酒店列表 |
| Top experiences | 8–15 个真正值得去的地方   |
| Food            | 必吃 + 菜名中文        |
| Getting around  | 地铁 / 打车 / 高铁     |
| Before you go   | 预约、支付、实名制等       |
| Chinese cards   | 地址、景点、菜名的中英对照    |
| Routes          | 典型 1–3 日路线       |
| Photos          | 大量高质量实景图         |

所以现有 **42 城 × 3 个 highlights** 只能作为 seed data，离正式产品还有明显距离。

---

### 2. ¥付费完整版 PDF：不是“网页打印版”

这是非常关键的一点。

用户不会因为“网站内容导出成 500 页 PDF”就付钱。

付费版应该更像一本**外国游客在中国真正能拿来执行旅行的工具书**。

比如一个景点不能只是：

> **Forbidden City**\
> The Forbidden City is one of Beijing's most famous attractions...

这种内容 ChatGPT 免费就能生成。

应该做到：

**Forbidden City · 故宫博物院**

📍 故宫博物院\
📱 给出租车司机看的中文地址\
🚇 最近地铁站\
⏱ 建议：3–4 hours\
🎟 是否需要预约\
🕐 推荐到达：08:30\
📸 最佳摄影位置\
🚶 推荐游览方向\
⚠️ 外国游客注意事项\
➡️ 下一站：Jingshan Park / 景山公园

然后配：

**实景照片 + 小地图 + 动线 + 中文地点卡。**

这种东西才开始产生“我到了中国以后真的会用它”的价值。

---

### 3. 最大差异化：China 对外国游客存在很强的「信息摩擦」

这是我认为这个项目最值得抓住的机会。

Lonely Planet 可以告诉游客“哪里值得去”，ChatGPT 可以帮他生成“北京三日游”。

但外国游客真正到了中国以后，经常面对另一类问题：

**这个地方中文叫什么？**

**应该在高德/滴滴里输入什么？**

**这个高铁站到底是 Beijing Station、Beijing South 还是 Beijing Chaoyang？**

**景点需要提前预约吗？**

**外国护照怎么买票？**

**支付宝怎么付？**

**酒店到底住哪个区域最方便？**

**打车给司机看什么？**

所以 China Unfold 可以增加一个非常有辨识度的产品模块：

### China Travel Cards

例如：

**THE FORBIDDEN CITY**

故宫博物院

北京市东城区景山前街4号

Show driver:

> 请带我去故宫博物院午门入口。

Metro:

Tian'anmen East\
天安门东站

Destination for map:

故宫博物院-午门

这类 Card 可以直接：

**Save to phone / Screenshot / Offline / Add to itinerary**

这比再写 1000 字故宫历史介绍更有产品价值。

### 4. 第二个付费产品应该比完整版 PDF 更重要：Personal Travel Book

用户输入：

**12 days / 2 travelers / October 10–21 / $4,000 / Beijing + Xi'an + Chengdu + Shanghai / history + food / medium pace**

不要只输出 ChatGPT 风格：

Day 1: Forbidden City\
Day 2: Great Wall\
Day 3: Summer Palace

而应该生成一本真正属于他的：

# YOUR CHINA JOURNEY

### Beijing · Xi'an · Chengdu · Shanghai

**12 Days · October 10–21**

然后每天都是完整视觉页面：

**DAY 04 — Beijing → Xi'an**

**北京西站**

这样用户购买的已经不是“AI 回答”，而是一份**个人旅行产品**。

这是项目很容易走偏的地方。

真正的视觉系统应该至少有四种图：

**A. Destination Photography**

建立情绪和旅行欲望。

例如：

不要复制 Lonely Planet。

### 8. 产品最终应该形成三层价值

| 产品目的付费               |                  |       |
| -------------------- | ---------------- | ----- |
| ChinaUnfold 网站       | 搜索、种草、建立信任       | Free  |
| Complete China Guide | 中国旅行知识库 + 离线工具   | 一次性购买 |
| My China Journey     | AI + 编辑数据生成私人旅行册 | 高一级付费 |

这里有个重要商业逻辑：

**真正更有潜力的不是完整版 PDF，而是 Personalized Travel Book。**

因为完整版 PDF 用户天然会问：

> “为什么不买 Lonely Planet？”

但私人旅行册对应的问题变成：

> “有没有人已经替我把这 12 天全部规划好了？”

这是完全不同的价值命题。

---

因此下一阶段，我认为不应该急着扩展 **42 → 100 城市**。应该先把：

**Beijing + Shanghai + Xi'an**

三个城市做到接近正式出版品质，再做一个：

**10-Day First Trip to China**

完整 Personalized Travel Book 样本。

如果这四部分做出来足够漂亮、足够实用，基本就能确定整个 **China Unfold 的内容模板、视觉系统、数据 Schema、PDF Schema 和网站 UI Design System**。之后扩展到 40–100 个目的地就主要是内容生产问题，而不是继续摸索产品形态。
