# Plan a Trip：全屏工作区与 Mapbox 评估

日期：2026-10-10。角色：Design → Engineering → Critic。

## 用户问题与实验假设

海外游客修改行程时，需要同时看见对话、每日安排和地理位置。原版长页面将行程放在对话中，地图只占页面一半。假设：铺满视口的三栏工作区能减少来回滚动，并让修改和地图反馈更容易理解。布局实现不表示此假设成立。

工具 A 的截图仅证明底图使用 Mapbox；截图中的景点、图片、评价、价格、开闭馆资料、路线估时可能来自其他供应商，不能归因于 Mapbox，也不能当成已核实的旅行事实。

## 可借鉴的点与优先级

| 点 | 对 Plan a Trip 的价值 | 本轮处理 |
| --- | --- | --- |
| 全视口三栏、独立滚动 | 修改时同时查看对话、安排、地图 | 已实现；窄屏切换 Assistant / Itinerary / Map |

| 日期导航与地图联动 | 快速定位某天和某站 | 中栏新增日期导航；复用原有选择状态和卡片修改回调 |
| 明确的修改摘要 | 知道删了什么、什么保留不变 | 建议下一步验证；现有助手文本仍显示，未新增自动摘要逻辑 |
| 路段上直接显示方式、分钟 | 不用逐条对照行程与地图 | 后续候选；必须使用实查路段数据，不能把虚线衔接当实际步行路线 |

## 本轮实现边界

- 只调整 Planner 工作区与它的路由外壳；经典版和其他页面保留原站点头尾。
- 宽度大于 1000px 时三栏并排；更窄时三视图切换。各栏有独立滚动区，输入区域固定在对话栏底部。
- 完整行程从对话中移至独立中栏；选择景点定位地图、卡片填入修改请求、新行程确认、撤销保持原回调。
- 不更换地图供应商，不修改生成、地理过滤、交通核实、餐饮、预约、数据回退的逻辑，不重置 Loop 状态。

## Mapbox 能替换什么

**评估结论：适合作为底图和绘制层候选；当前证据不足以作为高德全栈替代。**

- 多语言：官方示例支持创建地图时设定语言与运行时切换。英文标签有利于海外游客，但不是每个中国地点都有英文名称，仍须抽样检查。来源：[语言切换示例](https://docs.mapbox.com/mapbox-gl-js/example/language-switch/)。
- 地图表达：GL JS 支持定制样式、图层、标注与交互；日色、编号、路线、选中高亮可以作为应用自有数据覆盖物实现。截图的分类按钮和路线时间标签属于产品层工作，不是安装 SDK 自动得到的能力。来源：[GL JS](https://www.mapbox.com/mapbox-gljs)。
- 中国 POI：公开 Search Box 文档的 Supported geographies 列出美国、加拿大和欧洲，没有中国；同页存在日本示例，但不能据此推断中国支持。Geocoding v6 明确不提供 POI 数据。因此不可直接替换目前的中国景点/餐饮检索。来源：[Search Box](https://docs.mapbox.com/api/search/search-box/)、[Geocoding v6](https://docs.mapbox.com/api/search/geocoding/)。企业或区域产品需供应商另行确认。
- 公交/地铁：Directions API 仅列 driving-traffic、driving、walking、cycling 四个 profile，没有公共交通模式。地图显示地铁线并不意味着能计算乘车换乘路线。来源：[Directions](https://docs.mapbox.com/api/navigation/directions/)。
- 坐标：高德官方说明使用 GCJ-02；Mapbox API 要求 WGS84。不能直接把现有高德地点与整条路线顶点搬过去；需要确认所选地图产品坐标约定、获授权的数据来源及坐标对齐方案。来源：[高德坐标说明](https://developer.amap.com/faq/advisory/others/39838)、[Mapbox 坐标格式](https://docs.mapbox.com/api/guides/#coordinate-format)。
- 数据授权：高德服务协议限制超出授权范围的修改、翻译、衍生和再包装。混合供应商方案是技术候选，不能假定现有账户允许将地点/路线显示在第三方底图上。需先确认账户具体许可。来源：[高德服务协议](https://lbs.amap.com/pages/terms/) 第 7.2–7.3 条。
- 国内使用：本次没有 Mapbox 账户与 token，未测试游客到中国后各网络环境的瓦片、样式、字体加载与延迟；不能据此承诺可用性或覆盖质量。大陆发布使用哪个区域产品和许可，也需供应商确认。

## 服务费用与接入工作量

查询日官方 GL JS 价格：每月前 50,000 次加载免费；50,001–100,000 每千次 $5；100,001–200,000 每千次 $4；更高档阶梯下降。一次加载以 Map 对象初始化计数；缩放、平移、切换样式不另算加载；最长会话 12 小时，之后重新计数。**加载次数不是独立用户数。**

| 每月地图加载 | 仅 GL JS 地图费用，美元 |
| --- | ---: |
| 10,000 | 0 |
| 50,000 | 0 |
| 60,000 | 50 |
| 100,000 | 250 |
| 200,000 | 650 |

以上按阶梯价格推算，不含模型、高德、服务器、税费或企业/区域许可。Directions 另计，当前前 100,000 请求免费，下一档每千次 $2；其他 Search、Matrix、永久存储能力需分别计价，不能拿地图免费额度抵扣。来源：[官方价格](https://www.mapbox.com/pricing)、[加载计费说明](https://docs.mapbox.com/mapbox-gl-js/guides/pricing/)。

以下为本项目的工程估计，非供应商报价或工期承诺：

- 小范围验证版：约 2–3 工程人日，在账户、token、数据授权与坐标方案已确认后，显示一套获授权地点/路线，检查英文、标注、选中和加载失败。
- 当前地图展示层完整替换：约 5–8 工程人日，含每天配色、酒店、跨城段、完整行程/单天切换、真实路线与示意连接区别、移动端、性能、回退及回归。不含采购和供应商沟通周期。
- 全部地点与交通后端迁移：当前不具备可靠范围或估计依据；公共 POI 覆盖和公交能力缺口是先决问题。

最小下一步：先比较同一批上海地点在高德现有英文权限方案与 Mapbox 上的可读性、坐标一致性和国内访问；只在有实际改善且许可明确后替换展示层。

## 验证与未验证

- TypeScript 检查通过；相关三组件 ESLint 无错误/警告。
- 原有 workbench 回归通过：日期分配、锁定预约、冲突、跨城限制、保存恢复。
- 受控生产 POST 与真实 ItineraryOverview 组件渲染回归通过：时间/餐饮保留、混合语言说明、未知开放要求、跨城/缺失数据、路线失败与固定约束失败。受控数据不等于实查旅行事实。
- 开发服务器成功编译 `/en/plan` 并返回三个独立工作区和空行程提示；编译 CSS 包含全视口与窄屏规则。中文页与经典页另做服务端检查。
- 自动浏览器访问被浏览器 URL 安全策略拒绝；没有通过其他浏览器或工具绕过。桌面/手机视觉、实际滚动、焦点与地图点击尚未完成浏览器验收。
- 未运行新的真实模型旅行 Evals：本轮没有修改旅行逻辑；既有 T-001/Critic 失败仍保留，没有宣布产品假设成立。
